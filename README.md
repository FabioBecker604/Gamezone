# GameZone 🎮

A GameZone é uma loja virtual de jogos desenvolvida como projeto do curso Técnico em Informática do Senac.

## Funcionalidades

- Cadastro e login de usuários.
- Catálogo de jogos.
- Pesquisa e filtros por categorias.
- Página de detalhes dos produtos.
- Carrinho de compras.
- Finalização de pedidos.
- Simulação de formas de pagamento.
- Controle de estoque.
- Sistema de promoções.
- Painel administrativo.
- Cadastro, edição e exclusão de produtos.
- Gerenciamento de pedidos.
- Formulário de contato.

## Tecnologias utilizadas

- HTML5
- CSS3
- Bootstrap 5.3.3
- PHP
- MySQL
- XAMPP

## Como executar o projeto

1. Instale o XAMPP.
2. Coloque a pasta `gamezone` dentro de `htdocs`.
3. Inicie Apache e MySQL.
4. Crie um banco de dados chamado `gamezone` no phpMyAdmin.
5. Importe o arquivo `schema.sql`.
6. Configure a conexão com o banco em `config/conexao.php`, utilizando `config/conexao.example.php` como modelo.
7. Acesse `http://localhost/gamezone/`.
